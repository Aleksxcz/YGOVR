# VR Yu-Gi-Oh! Project

## Overview
Welcome to the **VR Yu-Gi-Oh! Project**, a fan-made virtual reality experience where you can duel in an immersive VR environment! This project allows players to engage in Yu-Gi-Oh! duels, interact with 3D cards, and use VR accessories for a fully immersive experience.

## Features
- **Fully Interactive VR Dueling**: Engage in real-time duels with fully animated cards and effects.
- **Hand Tracking & Motion Controls**: Draw, play, and move cards using intuitive VR hand tracking.
- **Customizable Accessories**: Equip VR duel disks, sleeves, and playmats for a personalized experience.
- **Multiplayer Mode**: Duel against friends and other players in an online multiplayer mode.
- **Realistic Arena Environments**: Choose from various iconic Yu-Gi-Oh! locations for your duels.
- **Deck Building**: Construct and customize your own deck using an in-game deck-building system.

## Controls
- **Hand Gestures**: Use your hands to pick up and place cards.
- **Voice Commands (Planned Feature)**: Use voice commands to activate certain emotes or effects.
- **Button Inputs**: Use controllers for additional actions like life point adjustments.
